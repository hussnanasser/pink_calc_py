# pink_calc_py

# 💗 Pink Python Calculator

A terminal-based calculator built with Python, with a pink-themed interface and support for common mathematical operations.

## ✨ Features

- 🩷 Addition, subtraction, multiplication, and division
- 🔢 Powers, remainders, and floor division
- 🧮 Square root calculations
- 📜 Calculation history during the current session
- 🛡️ Input validation and error handling
- 🎀 Pink and purple terminal colours
- 🔄 Interactive menu for repeated calculations

## 🛠️ Built With

- Python 3
- Python's built-in `math` module
- ANSI escape codes for terminal colours

## 🚀 Getting Started

### Prerequisites

Install Python 3. Check that it is available by running:

```bash
python3 --version
```

### Run the project

1. Clone this repository:

   ```bash
   git clone https://github.com/hussnanasser/pink_calc_py.git
   ```

2. Move into the project folder:

   ```bash
   cd pink_calc_py
   ```

3. Run the calculator (replace `calculator.py` if your Python file has a different name):

   ```bash
   python3 calculator.py
   ```

## 🧮 Supported Operations

| Operator | Operation | Example |
|---|---|---|
| `+` | Addition | `5 + 3 = 8` |
| `-` | Subtraction | `5 - 3 = 2` |
| `*` | Multiplication | `5 * 3 = 15` |
| `/` | Division | `6 / 3 = 2` |
| `**` | Exponentiation | `2 ** 3 = 8` |
| `%` | Remainder | `7 % 3 = 1` |
| `//` | Floor division | `7 // 3 = 2` |
| `sqrt` | Square root | `sqrt(25) = 5` |
